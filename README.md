# Sitio Web Personal - Dayana Portilla

Este proyecto contiene mi sitio web personal en dos versiones: una versión SPA moderna (con-framework) y otra MPA sin framework (sin-framework).

## 📁 Estructura del Proyecto

```
Pagina_Personal_DayanaPortilla/
├── con-framework/      
│   ├── index.html
│   ├── styles.css
│   ├── app.js
│   └── images/
├── sin-framework/      
│   ├── index.html
│   ├── contacto.html
│   ├── estudios.html
│   ├── pasatiempos.html
│   ├── proyectos.html
│   ├── styles.css
│   ├── script.js
│   └── images/
└── README.md
```

## 🚀 Versión con-framework (SPA Moderna)

La versión con framework usa un diseño SPA (Single Page Application) con navegación entre secciones.

### Características
- **Diseño Responsivo**: Funciona en móviles y escritorio.
- **Tema Oscuro**: Colores oscuros con acentos rosados.
- **Navegación SPA**: Sin recargas de página.
- **Formulario de Contacto**: Validación de campos en errores de formulario
- **Carrusel de Imágenes**: Galería en pasatiempos.


### Tecnologías
- HTML5, CSS3, JavaScript
- Bootstrap


### Cómo Ejecutar

Mediante el index.hmtl

### Ver Online
Accede al sitio desplegado en: [GitHub Pages](https://dayanaportilla.github.io/CV-DayanaPortilla/)


## 📱 Versión Sin Framework 

Versión multipágina con HTML puro y CSS personalizado.

### Características
- Páginas separadas para cada sección
- Diseño responsive
- Tema oscuro similar
- Formulario básico
- Carrusel de imágenes

### Tecnologías
- HTML5, CSS3, JavaScript

## 🎨 Diseño General

- **Tema**: Oscuro (#0f0f0f) con rosado (#d63384)
- **Tipografía**: Arial y Georgia
- **Layout**: Grid y flexbox
